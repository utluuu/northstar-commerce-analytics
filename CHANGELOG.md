# Changelog

All notable changes to this project are documented here. The format follows Keep a Changelog and the project uses semantic versioning for portfolio releases.

## [Unreleased]

### Added

- Windows setup and end-to-end reproduction guide.
- SQL Server and Power BI deployment acceptance checklist.
- Power BI manual build checklist.
- GitHub Actions CI for Python compilation, tests, and repository auditing.
- Automated checks for broken local Markdown links, unsafe artifacts, and oversized files.
- Contribution guidelines and release hygiene.

### Changed

- Expanded ignore rules for credentials, Power BI binaries, SQL Server files, local IDE settings, and test artifacts.
- Clarified local SQL Server authentication and certificate behavior in `.env.example`.
- Updated the license holder to a repository-neutral contributor identity.

## [1.0.0] - 2026-07-21

### Added

- Deterministic normalized e-commerce data generator with 12,000 customers, 600 products, 120,000 orders, and more than 250,000 order lines.
- SQL Server schema, constraints, indexes, analytical views, advanced queries, stored procedures, and quality checks.
- Modular Python EDA pipeline with data contracts, reconciliation, tests, business findings, charts, and Power BI-ready exports.
- Power BI star-schema blueprint, 65-measure DAX layer, measure dictionary, theme, Power Query guidance, and seven-page dashboard specification.
